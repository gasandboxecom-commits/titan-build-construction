# Titan Build Construction

A premium, responsive fictional Philippine construction company website built with Next.js, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Static export

`npm run build` creates the GitHub Pages-ready site in `out/`. Production assets use the `/titan-build-construction/` base path.

The contact form is a front-end demo. It does not transmit or store data.
